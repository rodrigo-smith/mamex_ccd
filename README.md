# Conservative Continuous Collision Detection for Multi-Axis Material Extrusion Toolpaths

This repository contains Jupyter/Python Notebook programs developed for my master's thesis.

The programs document the development of optimal discrete collision detection (DCD) and continuous collision detection (CCD) processes for multi-axis material extrusion (MAMEX) toolpath planning.

This repository is principally designed to allow academic scrutiny of the enclosed programs. It also makes them available for further work.

Program 1D is the final MAMEX DCD process. Program 2E is the final MAMEX CCD process.

Programs 1A-1C, 1E, and 2A-2D highlight chronological development stages of the project, to be considered alongside the accompanying thesis.
